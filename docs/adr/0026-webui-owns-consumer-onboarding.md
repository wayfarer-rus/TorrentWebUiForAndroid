# WebUI Owns Consumer Onboarding

Consumer Onboarding is a mandatory WebUI-owned first-use journey; Android remains the Android Startup Bootstrap and Fallback Control rather than duplicating the wizard. Android owns platform-permission acquisition, WebUI Port configuration and display, local Password Reset, daemon health, and emergency transfer controls because those capabilities depend on native lifecycle or physical-device access. The WebUI owns Onboarding Readiness, Approved Destination selection, and the optional Password choice so the primary consumer experience remains browser-first.

The Recommended Destination is a backend-proposed canonical filesystem path that Consumer Onboarding may create and approve; it is not an alias or document URI. Onboarding Readiness is the consumer-only projection of durable onboarding completion prerequisites, not a replacement for technical daemon health. Password Reset is the confirmed Android-local recovery operation that restores the default credential without exposing credential values.
