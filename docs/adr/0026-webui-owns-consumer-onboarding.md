# WebUI Owns Consumer Onboarding

Consumer Onboarding is a mandatory WebUI-owned first-use journey; Android remains a bare-bones Startup Bootstrap and Fallback Control rather than duplicating the wizard. Android owns platform-permission acquisition, WebUI Port configuration and display, local Password Reset, daemon health, and emergency transfer controls because those capabilities depend on native lifecycle or physical-device access. The WebUI owns onboarding readiness, Approved Destination selection, and the optional password choice so the primary consumer experience remains browser-first.
