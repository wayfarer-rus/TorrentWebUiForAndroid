# HTTP Basic Authentication for WebUI

The LAN WebUI uses HTTP Basic Authentication for static content, API routes, and `/ws/progress`, while the non-sensitive `/health` probe remains unauthenticated. The SharedPreferences-backed Password defaults to `start123`; normal settings changes require the current and new values, authenticated incomplete Consumer Onboarding uses a separate new-value-only contract, and Android provides reset-to-default recovery only. This browser-native scheme provides simple household-LAN privacy without sessions or cloud identity, but its base64-encoded credentials are unsuitable for public Internet exposure.
