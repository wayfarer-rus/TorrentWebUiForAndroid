# Product Brief

## Target User

A normal household user who wants to download files via torrent. They are not a torrent enthusiast. They do not want to configure trackers, DHT nodes, or piece sizes. They want to paste a link and get a file.

## Product Promise

"Safe, simple, remotely controlled downloader."

The user configures storage once, opens a browser on any LAN device, pastes a magnet link, chooses a named destination, and sees the completed file appear in their media storage — without touching technical settings.

## Anti-Goals

- **No public tracker/search portal.** The app does not browse or recommend torrents.
- **No social features.** No sharing, profiles, or community.
- **No crypto/mining.** No cryptocurrency integration or mining.
- **No remote Internet exposure by default.** The WebUI is LAN-only.
- **No configuration labyrinth.** Default settings work; advanced options are hidden.

## Success Metric

A user can:
1. Configure storage once during onboarding.
2. Open a browser on any LAN device.
3. Paste a magnet link.
4. Choose a named destination.
5. See the completed file appear in their media storage.

Without touching technical settings at any point.
