# 05 — Physical-Device LAN Acceptance

**What to build:** The remaining Milestone 2 acceptance proof that a physical Android device can serve the WebUI to a separate browser on the same LAN.

**Blocked by:** None — requires a physical Android device and separate LAN browser.

**Status:** ready-for-agent

- [ ] A separate LAN browser reaches the physical device WebUI and receives the expected authentication challenge.
- [ ] Browser controls add, observe, pause, resume, and remove a torrent while the Android UI shows consistent state.
- [ ] Password changes behave correctly across browser navigation and Android fallback settings.
- [ ] Actual device and network evidence is recorded without claiming emulator results as LAN proof.
