# 01 — Headless Emulator Acceptance Environment

**What to build:** A reproducible, minimally provisioned emulator and host-browser environment that can install the app, collect Android UI evidence, and reach the emulator-local WebUI.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Existing tooling is assessed first; only the minimum required host/browser automation tools are installed.
- [ ] Any new dependency has its purpose and license recorded before the acceptance result is published.
- [ ] A fresh app install reaches a clean health-ready state on the existing emulator.
- [ ] The environment can collect UI screenshots and reach the emulator-local WebUI from the host.
